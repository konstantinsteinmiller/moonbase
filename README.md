# Project: Moonbase

Project: Moonbase is a robot exploration game on the moon, who is advised by a trillionaire called Ekon Tusk.

It features a github pages deployed CI cd pipeline and a windows build + demo build.

WIP: [playable demo](https://konstantinsteinmiller.github.io/moonbase/)
